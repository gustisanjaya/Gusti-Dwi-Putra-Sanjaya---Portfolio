# Gusti Dwi Putra Sanjaya - Portfolio

Portfolio website / CV Online untuk IT Specialist & Web Developer.

## 📋 Deskripsi

Single page portfolio yang menampilkan informasi profesional, pengalaman kerja, keahlian teknis, pendidikan, dan proyek-proyek yang pernah dikerjakan.

## 🛠️ Teknologi

- HTML5 (Semantic)
- CSS3 (Responsive, Mobile-first)
- Bootstrap 5
- Google Fonts (Inter)
- Bootstrap Icons

## 🚀 Cara Menjalankan

1. Buka file `index.html` di browser
2. Atau gunakan Live Server di VS Code

## 📱 Fitur

- Navigasi smooth scroll
- Active navbar highlight
- Palette warna custom background
- Download as PDF
- Responsive design
