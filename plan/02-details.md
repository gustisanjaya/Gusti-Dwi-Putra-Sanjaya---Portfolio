## Komponen yang Dipertahankan

### Navigation ( <nav> )
- Navbar fixed-top dengan brand logo dan menu
- Active link highlight saat scroll
- Smooth scroll ke section tujuan

### Main Content ( <main> )
- Profile header ( <header> ) dengan nama, gelar, status badge
- Contact grid (email, telepon, LinkedIn, GitHub, alamat)
- Section: Ringkasan profesional
- Section: Pengalaman kerja (3 perusahaan)
- Section: Keahlian teknis (3 kategori)
- Section: Pendidikan (2 institusi)
- Section: Proyek terpilih (3 proyek)
- Section: Informasi tambahan (bahasa, sertifikasi)
- Section: Kontak dengan contact cards
- Tombol download PDF

### Footer ( <footer> )
- Copyright dan credit

### Ekstra Fitur
- Palette container (7 warna untuk custom background)
- Script toggle palette
- Script active navbar
- Script smooth scroll
- Script print/PDF dengan loading state
